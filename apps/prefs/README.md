# prefs

MixOS's preferences: one window with a flat sidebar: Appearance, Text & Fonts, Windows, Apps (Email, Term, Ced), Accessibility, and Software & Updates. Wallpaper opens from Appearance. Each page says what it affects; settings retain their existing keys and apply behaviour.

Documentation: <https://mixos.dev/prefs/> — source [`docs/prefs/README.md`](../../docs/prefs/README.md).
