# props

Shared property read types, revision handling and optional ABP publication
builders. [noded](../noded/README.md) and subsequent Mix and
[editd](../editd/README.md) consumers share this surface without a database
or a second control transport.

The default feature set contains pure types and in-memory revisions. The
`bus` feature adds read dispatch and publication envelopes.
