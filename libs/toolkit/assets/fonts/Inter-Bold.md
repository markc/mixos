# Inter Bold

`Inter-Bold.ttf` is the unmodified static 700 face from `extras/ttf/Inter-Bold.ttf`
in [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1), the same release
as the bundled Light, Regular, Medium and SemiBold faces. Its SIL OFL 1.1
licence is `OFL-Inter.txt`; the release's `LICENSE.txt` is byte-identical.
`NOTICE` and the Inter file annotation in `REUSE.toml` cover this face.
