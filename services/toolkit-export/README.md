# toolkit-export

GTK and Qt follow the desktop's settings: a per-session Mix citizen that writes the look settingsd computes into the desk's GTK and qt5ct/qt6ct files, one way, keeping the user's own edits and every original for undo.

Documentation: <https://mixos.dev/toolkit-export/> — source [`docs/toolkit-export/README.md`](../../docs/toolkit-export/README.md).

`mix services/toolkit-export/tests/toolkit_test.mix` tests the renderer;
`mix services/toolkit-export/tests/export_test.mix` runs the citizen on a
private broker against a stand-in settingsd.
